# 🎓 Sistem Sijil Berhenti Sekolah

Aplikasi web ringkas untuk guru **menjana sijil berhenti sekolah secara automatik**, boleh **kemas kini** dan **cetak semula** bila-bila masa.

## ✨ Ciri-ciri
- Isi 14 medan maklumat murid + jadual pencapaian
- Simpan senarai murid (data kekal dalam browser / localStorage)
- Kemas kini (Edit) data bila ada perubahan
- Cetak / simpan PDF sijil bila-bila masa
- Muat naik **satu logo sekolah**
- Nama Guru Besar **TETAP**: NOR HAMIZAH BINTI DAUD
- Nama Sekolah & Tahun boleh diubah

## 🚀 Cara Guna

### Pilihan A — Terus dari komputer (paling mudah)
1. Muat turun fail `index.html`
2. Klik dua kali untuk buka dalam pelayar (Chrome / Edge)
3. Mula guna!

### Pilihan B — Guna online (GitHub Pages)
1. Pergi ke **Settings → Pages**
2. Di bahagian *Source*, pilih branch **main** dan folder **/ (root)**, klik **Save**
3. Tunggu satu-dua minit, buka pautan yang diberi (cth: `https://sitifaizahhassan.github.io/sijil-tamat-persekolahan/`)

## 📝 Langkah Penggunaan
1. **Tetapan Sekolah** — isi nama sekolah, tahun & muat naik logo → **Simpan Tetapan**
   - (Nama Guru Besar sudah tetap, tak perlu isi)
2. **Tambah Murid** — isi borang → **Simpan Murid**
3. **Senarai Murid** — klik:
   - **Edit** untuk kemas kini
   - **Cetak** untuk jana & cetak semula sijil
   - **Padam** untuk buang data

## 💡 Nota
- Data disimpan dalam pelayar komputer yang sama. Guna komputer yang sama untuk akses semula data.
- Semasa cetak, pilih **"Save as PDF"** jika mahu simpan salinan digital.
